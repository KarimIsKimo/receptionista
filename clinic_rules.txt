# Clinic operations source of truth

Runtime clinic logistics and booking rules are defined in `receptionist/clinic.py`.

Do not duplicate opening hours, slots, timezone, address, branch, closed days, or booking horizon here or in prompts. Update `CLINIC` there; `clinic_prompt()` injects the same values into Gemini.

The editable dashboard system instruction remains responsible for tone, laser FAQs, prices, and escalation guidance. Runtime booking validation always uses the authoritative Python configuration.
